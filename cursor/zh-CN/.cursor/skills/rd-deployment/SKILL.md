# $rd-deployment

规划和执行**安装部署**，产出可重复的部署操作手册和变更记录。

> **与 `$rd-technical-writing` 建设方案的边界**：建设方案定义部署的*设计*（基础设施拓扑、环境规划、部署策略、容量规划）；本 Skill 负责部署的*执行*（操作手册、脚本编写、回滚验证、变更记录）。建设方案是本 Skill 的输入之一。

## 交付物

- 部署操作手册（逐步操作、回滚、验证）
- 部署脚本 / 自动化配置（如适用）
- 部署变更记录
- 部署后验证清单

## 执行步骤

### 1. 部署范围确认

- 确认部署内容：代码版本、配置变更、数据库迁移、基础设施变更
- 确认目标环境：开发/测试/预发布/生产
- 确认前置条件和依赖项（含测试是否已通过 `$rd-testing`）
- 确认部署窗口和影响范围

### 2. 部署方案编写

#### 部署步骤
- 逐步骤列出操作命令或流程
- 每步骤标注预期结果和超时时间
- 标注需要人工确认的关键检查点

#### 回滚方案
- 每个关键步骤的回滚命令/操作
- 回滚决策条件（什么情况下触发回滚）
- 回滚后的验证步骤
- 数据回滚策略（如涉及数据库变更）

#### 灰度/分批策略（如适用）
- 分批比例和节奏
- 每批次的观察指标和推进条件
- 异常时的暂停和回退流程

### 3. 环境检查清单

| 检查项 | 内容 |
|--------|------|
| 版本确认 | 部署包版本、依赖版本 |
| 配置核对 | 环境变量、配置文件差异 |
| 资源就绪 | 数据库连接、中间件、外部服务 |
| 权限确认 | 部署账号权限、文件系统权限 |
| 备份确认 | 数据库备份、配置备份 |

### 4. 部署执行

- 按方案逐步执行
- 每步记录实际结果
- 异常情况及时记录和决策

### 5. 部署后验证

- 冒烟测试：核心功能可用性
- 监控确认：错误率、响应时间、资源使用
- 日志检查：无异常错误日志
- 业务验证：关键业务流程正常

### 6. 变更记录

输出标准化变更记录：
- 变更时间、执行人
- 变更内容摘要
- 影响范围
- 验证结果
- 遗留问题

## 规范注入检查

执行前检查：
- `.cursor/rules/` 中的项目部署流程和审批要求
- 已有的 CI/CD 管道配置
- 环境管理规范和访问权限
- 变更管理制度

## 工具使用

- **Context7**：查询部署工具和基础设施文档
- **客户端内置浏览器能力 / Playwright CLI / Playwright MCP（按需）**：Web 应用部署后的自动化冒烟测试；默认优先 CLI 或客户端内置浏览器能力

## 质量门禁

交付前核查：

- [ ] 部署步骤可重复执行
- [ ] 回滚方案存在且可执行
- [ ] 关键检查点已标注
- [ ] 部署后验证通过
- [ ] 变更记录完整

## 不做

- 不跳过回滚方案
- 不在没有备份的情况下执行数据库变更
- 不在生产环境做未经测试的操作
- 不忽略部署后验证
