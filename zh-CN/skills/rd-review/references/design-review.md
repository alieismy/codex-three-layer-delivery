# 设计评审

## 评审维度

- 接口契约：不变式、输入、输出、错误、顺序、版本和幂等
- 数据模型：生命周期、约束、索引、一致性、保留和迁移假设
- 关键流程：正常、异常、超时、部分成功、重试和恢复路径
- 状态与并发：合法转换、竞争、锁和冲突处理
- 安全：信任边界、授权、校验、数据保护、密钥和审计
- 可观测性、错误处理、可实施性和对已批准输入的追踪

## 失败假设

- 调用方必须知道未记录的实现细节才能安全使用接口
- 部分失败或并发执行破坏不变式
- 安全或数据流跨越未建模的信任边界
- 未决设计事项被表述为已确定事实

## 证据

平台约束和当前 API 行为实质影响可实施性时，应核实实际限制。
