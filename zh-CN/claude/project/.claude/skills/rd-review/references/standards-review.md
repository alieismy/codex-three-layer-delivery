# 标准评审

## 评审维度

- 效力、文档状态、范围、读者和适用起草规则
- 技术正确性及与规范性引用文件的一致性
- 强制、推荐、允许和资料性内容的区分
- 可验证性、可执行性、术语、符号、图、表和引用
- 内部冲突及与上位法律、政策或标准的冲突
- 除非标准有意约束实现，否则保持实现中立

## 失败假设

- 规范性条款使用模糊动词或不可验证形容词
- 被引用文件的名称、状态、适用性或条款内容未经核实
- 资料性内容被误写为强制要求，或反之
- 专家偏好被表述为有权威依据的要求

## 证据

明确具体条款和权威来源。规范性文本不可访问时，只评审已核实元数据，并把内容标记为需要人工确认。
