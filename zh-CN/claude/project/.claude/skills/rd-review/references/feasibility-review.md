# 可研评审

## 评审维度

- 决策问题、范围、现状基线和候选方案
- 事实、估算、假设和未知项是否分离
- 技术、经济、进度、运行、安全、合规和风险维度
- 成本与进度估算依据、敏感性和不确定性
- 条件、阻塞项、回退方案和核验动作
- 证据和条件是否匹配所声明的决策阶段，包括有依据支持的试点与生产承诺之间的边界
- 创新、演进或采用影响决策时，是否考虑重要机会成本、学习价值和可信候选方案
- 结论是否来自证据而非偏好

## 失败假设

- “可行”掩盖未决条件或外部依赖
- 推荐方案只与薄弱或缺失的替代方案比较
- 成本、进度、成熟度、政策或标准结论没有来源
- 风险清单没有改变决策或核验计划
- 以缺少生产证据否定其他条件已获支持的有界试点，或试点推荐隐藏了启动前必须满足的条件
- 用新颖或熟悉代替对价值、证据以及延迟行动或沿用现状成本的比较

## 证据

时效性结论使用当前权威来源，并显式标记无法取得的证据。
