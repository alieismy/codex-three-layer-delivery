# 共享指令：GPT-5.6 Sol 与 GPT-6 Astra

日期：2026-09-20。状态：已完成基于所提供文本的有边界评估，保留失败；原生验证受阻。

## 决策与范围

保留一套共享指令，包括此前的两项 [Astra 改动](astra-guidance-adoption.md)：附来源链接的阻塞说明，以及可选的授权与完成条件提示块。九个 Skill 的正文、描述、调用策略、权限边界和个人配置保持不变。为 `rd-writing` 新增带有合成资料的简短决策简报回归用例 eval 4，同步英文、中文、Claude 与 Cursor 镜像。每个 canonical 语言目录现有 44 个输出 eval；这是用例数量，不是运行测试通过数量。

本次运行前提是**两个请求模型均使用 high 推理与 high 输出详细程度**，没有为 Astra 降低推理档位。具体任务的长度要求仍约束简报输出。相同的 effort 标签不证明相同算力或能力。

保留现状的最强反对理由，是 Sol 的阻塞依据遗漏已经复现，确实未满足注入文本的契约。但目前没有受控干预把问题归因到某条指令，也没有证明某项共享修正能解决它且不引入回归。因此保留失败样本并作为后续验证目标，不据此宣称完全兼容，也不重写所有 Skill。

## 首轮结果

每个请求模型执行 11 个场景，注入**当前最终全局和项目模板**、责任 Skill 正文、相关参考及合成输入。这与早先 Astra A/B 实验不同，没有把历史 B 组的旧全局文本当成当前组合。八个场景为英文、三个为中文。断言在运行前冻结且不提供给模型。任务代理完整阅读并评分，评分并非独立或盲评。

22 次首轮进程均正常退出、没有错误事件，完成项只有 `agent_message`。进程成功不等于断言通过。对 Sol A1 预先声明的一次同条件复现仍为 3/5，再次遗漏链接与原条款引用。复现单独保存，不计入首轮总数，两个样本互不替换。没有为追求通过而重跑其他评分案例。

## 原生检查及证据上限

四次隔离的原生尝试覆盖显式 `$rd-review` 与 `$rd-requirement` 调用，每个请求模型各一次。测试放置当前全局及项目模板，只把责任 Skill 复制到项目 Skill 根目录，并排除 eval 文件。启用 shell 与执行工具，使用 `workspace-write` 和 `never` 批准策略。

四次代理均报告执行策略拒绝。保留的事件没有已完成命令或文件改动，运行前后清单相同。两次 PRD 尝试保留了原阈值，父进程执行 checker 失败，预期文档精确比较为 false。两次评审均未给出实质性 finding 判定。**四次原生尝试全部受阻，不计作通过。** 文件未变不能单独证明遵守“只评审”。

对隔离测试 home 日志的有边界检查没有发现匹配的拒绝诊断。因此，策略拒绝是代理自述，根因没有获得独立确认。没有放宽权限，也没有盲目重复四次尝试。在证明已授权工具路径可用前，原生 Skill 加载、执行和权限实施仍未验证。

## 复现与完整性

权威 JSON 包含冻结输入及来源哈希、提示组合与哈希、完整最终回答及哈希、冻结断言、评分、逐字和长度检查、执行顺序、用量、耗时、单独的诊断及脱敏原生材料。历史 [Astra 证据](../../docs/evidence/astra-guidance-eval-2026-09-20.json)保持不变。

使用 `"\n\n".join(record["inputs"][key] for key in case["prompt_parts"])` 重建首轮提示，并将 UTF-8 SHA-256 与 `case["prompt_sha256"]` 比较。回答哈希对应保留的字符串；原生回答哈希对应公开的路径脱敏文本，另存原始哈希以标识未修改的本地原件。公开记录排除凭据、私有 provider 信息和个人绝对路径。

本次使用 Windows、`codex-cli 0.155.1`，每个样本使用独立临时 home/workspace 与新的 ephemeral 进程，显式 high/high，复用已授权认证，单次上限 240 秒。基于所提供文本的运行禁用可发现 Skills、项目文档加载、shell、网络检索、apps、plugins、hooks、memories 与多代理。两次上下文探针均返回 `none`；这只是模型自述加配置证据，不证明强隔离。注入前言也禁止工具，因此不能据此衡量实际工具效率。实验 CLI 观察不更新仓库锁定的发布 schema 或更广泛测试基线。

任务临时脚本不是新的受支持框架。公开记录足以重建评估输入，无需私有路径或忽略文件。获授权的复现仍需可用的 CLI/provider 认证与等价控制，宿主及后端差异可能影响结果。
