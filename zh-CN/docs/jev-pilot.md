# 可选 Jev 语义检查试验

日期：2026-09-21。状态：已完成真实 API 试验，仅作辅助判断。

## 决策

在代码完成精确检查后，选择性地使用 Jev 进行范围明确的语义分类和筛查。证据选择、复杂推理、分歧复核和最终结论由 Codex 负责。本次发现一条高置信度误报，因此模型的通过标签或置信度阈值都不能授予文档批准、消除失败记录或授权操作。

用户级 `typesafe-ai` Skill 提供接入指导，不等于安装模型、提供 API 凭据或接管宿主 Skill 路由。下文可选脚本只实现一个有边界的试验，不新增公共 Skill、默认外部依赖、第二套路由、强制流程或发布门禁。

## 方法与结果

源记录有十一个案例，每个案例包含两份最终回答。脚本定义了 39 个案例级条件，对应 78 次回答级判断：英文回答 56 条、中文回答 22 条；所有问题使用英文。这些是新的局部条件，不是原来的 96 条复合断言。尤其是“明确声明合成材料”比“没有宣称真实部署”更严格，不覆盖或静默重算原评分。

每次请求的 `state` 包含完整历史最终回答及相关虚构场景和任务。全局规则、项目规则、完整 Skill 正文、原评分、模型标签及预期标签均不发送。请求哈希、选定输入键、回答哈希、问题目录和脚本哈希支持重建请求。模型读取完整回答，不是关键词摘录；问题明确要求区分来源材料与待评回答。

Jev 返回 **73 个 `satisfied`、5 个 `violated`、0 个 `uncertain`**。这是模型标签，不能表述为 73 项已验证通过。五个标记都涉及未明确说明材料为虚构：

| 样本 | 历史回答 | Jev 置信度 | Codex 裁决 |
|---|---|---:|---|
| S04 | 英文静态评估 | 0.95 | **误报。** 第二节已有 “The assessment is limited to the supplied synthetic records:” |
| S09 | 英文已完成证据说明 | 0.99 | 完整阅读后确认遗漏 |
| S15 | 英文简报的第一份回答 | 0.98 | 完整阅读后确认遗漏 |
| S16 | 英文简报的第二份回答 | 1.00 | 完整阅读后确认遗漏 |
| S21 | 中文简报的第一份回答 | 0.92 | 完整阅读后确认遗漏 |

当前任务 Codex Agent 完整阅读五份被标记回答，并抽查覆盖八类问题和中英文的十份未标记回答，其 34 条选定条件与回答原文一致。剩余 39 条 `satisfied` 条件没有逐项裁决。这不是人工评审、独立审计或盲化参考标注：任务 Agent 能看到历史记录和 Jev 标签。执行前没有冻结参考标签，没有调阈值，也没有独立留出集可靠性结论。未重新运行或替换误报样本以取得通过。

确定性检查单独保留了英文政策链接及原文条款遗漏、中文政策链接遗漏、英文简报 239 词超过 220 词，以及中文 PRD 新增三处空行导致精确保留失败。中文 PRD 可以满足两条语义条件，同时未通过精确保留检查。局部语义通过不代表整个回答可接受。

22 次主要请求共使用 **48,068 个输入 token、3,521 个输出 token**。顺序请求耗时为 **0.875–1.152 秒**，**中位数 0.943 秒**，**请求耗时合计 21.264 秒**。这不含准备、阅读、解释、测试和文档工作，不能证明净节省时间。加上独立预检，总调用为 23 次，输入用量为 48,454 token。按报告日期核对的[官方价格](https://docs.typesafe.ai/models)，主要推理费用估算为 **0.002019 美元**，含预检约 **0.002035 美元**；未核对实际账单。

## 重现有边界的试验

[脚本](../../scripts/run-jev-pilot.py)使用 Python 3.9+ 标准库 HTTP 能力，不需要安装 SDK 或新增依赖。以下命令从仓库根目录运行。

离线查看请求数量、来源哈希和确定性检查结果，无需网络或凭据：

```powershell
python scripts/run-jev-pilot.py preview
python scripts/test-jev-pilot.py
```

在已授权传输这些公开虚构输入并承担少量 API 费用后，令进程可以读取 `TYPESAFE_API_KEY` 再运行。新添加的 Windows 用户环境变量可能尚未进入已经启动的终端；示例只为本次命令导入，并恢复原进程值，不输出密钥：

```powershell
New-Item -ItemType Directory -Force .tmp/local/jev-pilot | Out-Null
$previousKey = $env:TYPESAFE_API_KEY
try {
    if (-not $env:TYPESAFE_API_KEY) {
        $env:TYPESAFE_API_KEY = [Environment]::GetEnvironmentVariable('TYPESAFE_API_KEY', 'User')
    }
    python scripts/run-jev-pilot.py run --output .tmp/local/jev-pilot/new-run.json
    if ($LASTEXITCODE -ne 0) { throw 'Jev pilot did not complete; inspect the retained record.' }
}
finally {
    $env:TYPESAFE_API_KEY = $previousKey
}
```

目标文件必须不存在；再次授权运行时使用新文件名。脚本校验返回模型、问题键、类型、概率范围和用量，不携带凭据跟随重定向。只有 429/529 允许一次有上限的重试，并遵循不超过 30 秒的数字 `Retry-After`；其他错误结束执行。每次调用结果在继续前保存。失败运行保持部分完成状态，不能算通过；脚本不自动续跑或替换旧样本。

该脚本只面向固定的 9 月 20 日公开记录，不接受任意文档。扩展到新材料或私人材料时，需要确定相应输入范围、审查发送内容并定义适合该任务的条件。仅修改文件名或调用 Skill 不能产生验证证据。

## 建议的任务提示词

以下是可选任务提示，不是常驻规则：

> 使用 typesafe-ai Skill。复杂推理、证据解释和最终结论由 Codex 负责。对于已授权材料中适合独立判断的局部语义分类、筛选和简单判断，优先使用 Jev；精确规则、计算和文本比较使用代码。复核不确定结果及问题标记，并抽查未标记结果。模型置信度不能授予批准。说明哪些步骤实际调用了 Jev，并报告模型、输入范围、请求数量、费用证据、失败和未验证边界。除非本任务明确包括路由试验，否则沿用既有路由。

本仓库首个已演示入口是评估辅助。主张与引用支持关系检查可作为下一候选，中英文语义对照和 Skill 路由继续延期。小规模 Skill 目录和既有路由不构成每轮额外调用模型的理由。

仓库正向验证、既有 20 项 Validator 负向用例，以及五项专门的离线试验测试均通过。任务完整性检查重建了全部 22 次请求，验证全部 78 条类型化结果，将每份保留复核摘录与未修改的历史回答匹配，并检查本地链接、UTF-8/LF 格式、变更/新增制品中的实际密钥值和有限敏感模式。`git diff --check` 通过。这些检查验证制品和错误处理，不证明模型可靠性。未执行仅发布时需要的联网门禁，未提交、推送或发布。

2026-10-02 修复为服务响应增加明确的对象形状检查，离线测试增至七项，包含异常响应下的部分证据保存。原有 22 次 API 调用未重跑或重新标注。[冻结的历史执行脚本](../../docs/evidence/jev-pilot-runner-2026-09-21.py)与原始证据中的 `runner_sha256` 一致，重建时应在隔离检出中将归档字节恢复到 `scripts/run-jev-pilot.py`，再执行 `preview`；证据目录中的归档不是直接执行入口。当前执行脚本包含本次修复。

## 证据限制与来源

- [Introduction](https://docs.typesafe.ai/introduction)、[Choice](https://docs.typesafe.ai/primitives/choice)和 [HTTP API](https://docs.typesafe.ai/api)规定类型化问题契约；类型正确不证明判断正确。
- [Confidence](https://docs.typesafe.ai/confidence)解释从概率分布计算置信度。S04 直接说明不能将它理解为批准概率。
- [Jev 已知限制](https://docs.typesafe.ai/model-jaggedness/jev-1.13)包括无关上下文、字面理解及对抗性内容影响。本试验没有隔离 S04 根因，也没有验证对抗鲁棒性。
- [Models](https://docs.typesafe.ai/models)说明非英文表现较弱，以及当前输入和价格限制。本次小规模混合语言样本不能证明中文等效或未来模型兼容。
- [隐私政策](https://typesafe.ai/legal/privacy-policy)和 [Legal](https://docs.typesafe.ai/legal)区分不训练承诺与企业零留存。只发送公开虚构任务材料和历史最终回答，不发送个人配置、凭据或私人会话历史。

本试验支持可选辅助使用，不证明默认模型偏好、已校准分类器、替代评审者、原生路由接入、生产验收或发布决定。后续只在代表性任务证据表明计入复核成本后仍有收益时继续推进。
