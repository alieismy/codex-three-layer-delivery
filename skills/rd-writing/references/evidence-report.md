# Evidence Report Mode

Use for research syntheses and fact-check reports.

## Recommended Structure

1. Question, scope, date boundary, and method
2. Executive conclusion with confidence
3. Claim-by-claim findings
4. Evidence table and source limitations
5. Counterevidence and alternative explanations
6. Unresolved questions and verification actions
7. Sources

For each claim, state the verdict, evidence, reasoning, and boundary. Preserve uncertainty and distinguish unsupported from contradicted. A fact-check report should make the method auditable rather than merely announce labels.
